# M6 — Core user experience

Status: **NOT STARTED**
Dependency: M5 truthful role-specific behaviour

## Objective

Make contractor and job-seeker journeys focused, mobile-friendly, accessible,
recoverable, and usable in English and Hindi.

## Planned scope

- Role selection/onboarding and profile progress.
- Role-focused dashboard, detail, save, advisory analysis, workspace, planner,
  and alert journeys.
- Empty/loading/error states and recoverable actions.
- Hindi completion for core journeys.
- Mobile/desktop layout, keyboard navigation, contrast, semantics, and essential
  accessibility tests.
- Support/contact/report flows and removal of dead/placeholder actions.
- Provider-neutral analytics with local/free fallback.

## Exit criteria

- Core journeys pass on mobile and desktop.
- New users complete onboarding without assistance.
- No critical dead actions or irrelevant role navigation.
- Essential accessibility checks pass.
- English and Hindi core journeys function.
